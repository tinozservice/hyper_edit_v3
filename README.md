# HyperEdit

AI-powered video editor — local-first. React 19 + Remotion for motion graphics, a Cloudflare Worker for the deployed API, and a Node "ffmpeg server" that owns sessions, rendering, transcription and AI generation on your machine.

Built on the [Mocha](https://getmocha.com) platform.

## Features

- **Multi-track timeline** — T1 (text/captions), V3/V2/V1 (overlay → base video), A1/A2 (audio), with drag, trim, split, ripple delete and auto-snap.
- **AI agents (right panel)**
  - **DIRECTOR JEV** — chat-driven editing: FFmpeg edits, captions, motion graphics, AI animations, timeline arrangement (Jev routing), image-to-video, plus `.txt`/`.md` notes as instructions.
  - **Obsidian / JEV** — media agent over an Obsidian vault (logos, brand assets, b-roll) with singular/plural asks.
  - **DiCaprio** — Animate Image (image-to-video via the fallback pool's Video provider or fal.ai), Restyle Video, Remove Background.
  - **Creator OS** — publish renders through the `@creatoros/cli`.
  - **Shorts** — find viral moments in a long video and cut vertical shorts with burned-in hooks.
  - **YouTube** — native OAuth upload (Data API v3) with Shorts hashtag handling.
- **AI motion graphics** — Remotion `DynamicAnimation` scenes (title, steps, stats, charts, countdown, emoji, GIF, Lottie, media…) generated by the LLM fallback pool, editable in-place.
- **Captions & transcription** — local Whisper → OpenAI-compatible Whisper pool → Gemini fallback; word-level karaoke captions; dead-air removal.
- **Fallback LLM pool** — every chat / transcription / TTS / video request tries an ordered provider list stored in SQLite (`data/llm.db`) and managed at `/settings/llm`. Text-only features use the pool first; Gemini is a last resort for multimodal work.
- **Media library** — AI-generated media (animations, generated images/videos, restyle, remove-bg, b-roll) is stored in `MEDIA_LIBRARY_DIR` (default `D:\Project\Shorts\Media-AI`) sorted by date, so deleting a session never removes it. Uploads stay in the session dir.
- **Saved projects** — Save/Open Project in the header; saved sessions are pinned against the 2-hour auto-cleanup and can be rebuilt from a snapshot.
- **Aspect ratio picker** — presets + custom pixel dimensions for the canvas and export.

## Requirements

| Need | Notes |
|---|---|
| **Node.js ≥ 22.5** | Uses built-in `node:sqlite` for the LLM pool; tested on Node 24 |
| **FFmpeg + FFprobe** | Required for almost every video feature. The server auto-discovers it (PATH, winget links, `C:\ffmpeg\bin`, Chocolatey, Scoop). Windows: `winget install Gyan.FFmpeg` |
| **Chrome / Edge** | Voice mode (Web Speech API); Remotion downloads its own Chrome Headless Shell on first render |
| **Python + openai-whisper** *(optional)* | Free local transcription: `pip install openai-whisper torch` |
| **API keys** *(optional)* | See `.dev.vars.example`; everything is managed through the fallback pool |

## Getting started

```bash
npm install --legacy-peer-deps        # Vite 7 peer-dep conflict needs the flag
Copy-Item .dev.vars.example .dev.vars # fill in the keys you have
```

Run **two** processes in separate terminals:

```bash
npm run ffmpeg-server   # editor API + media library + LLM pool  (http://localhost:3333)
npm run dev             # UI + Cloudflare Worker               (http://localhost:5173)
```

Open <http://localhost:5173>, upload media, and edit. Manage LLM providers (chat / transcription / TTS / video) at <http://localhost:5173/settings/llm>.

## Configuration

All environment variables live in `.dev.vars` (copy from `.dev.vars.example`). Highlights:

| Variable | Purpose |
|---|---|
| `ANTHROPIC_API_KEY` / `OPENAI_API_KEY` | Seeded into the fallback pool on first run (chat, Whisper, TTS) |
| `GEMINI_API_KEY` | Last-resort multimodal fallback (audio/video transcription, B-roll images, chapters) |
| `FAL_API_KEY` | fal.ai: Restyle Video / Remove Background, Animate Image fallback |
| `GIPHY_API_KEY` | GIF search |
| `OPENROUTER_API_KEY` / `JEV_MODEL` | Jev (System One) routing via OpenRouter |
| `TYPESAFE_API_KEY` | Legacy direct TypeSafe access for Jev |
| `YOUTUBE_CLIENT_ID` / `YOUTUBE_CLIENT_SECRET` | Native YouTube upload OAuth |
| `OBSIDIAN_VAULT_PATH` | Vault for the media agent (Windows runs in *direct* mode) |
| `MEDIA_LIBRARY_DIR` | AI media storage root (default `D:\Project\Shorts\Media-AI`) |
| `FFMPEG_PATH` / `FFPROBE_PATH` | Override binary locations when auto-discovery misses them |
| `LLM_FALLBACKS` | Worker-only JSON provider list for production deployments |

Secrets are **not** committed: `.dev.vars` and the whole `data/` folder are gitignored.

## Architecture

```
src/
├── react-app/           React SPA — editor UI, panels, timeline, settings pages
├── worker/              Cloudflare Worker (Hono): deployed API, chat/FFmpeg orchestration
├── remotion/            DynamicAnimation + static motion-graphics templates
└── shared/              Shared types
scripts/
├── local-ffmpeg-server.js  Sessions, assets, rendering, AI generation, projects, media library
├── llm-pool.js             SQLite-backed chat/transcription/TTS/video fallback pool
├── jev.js                  Jev (System One) client — workflow routing
├── obsidian-agent.js       Obsidian vault media agent
├── youtube-client.js       YouTube OAuth + upload
└── whisper-transcribe.py   Local Whisper helper
data/                   llm.db, projects.json, project snapshots (gitignored)
```

**Storage at a glance**

- **Sessions** — `%TEMP%/hyperedit-ffmpeg/sessions/<id>/` (project state, renders, uploads); auto-cleaned after 2 hours unless pinned by a saved project.
- **Media library** — `D:\Project\Shorts\Media-AI/<YYYY-MM-DD>/` for AI-generated media (configurable).
- **Projects** — `data/projects.json` registry + `data/projects/<id>/` snapshots.
- **LLM pool** — `data/llm.db` (providers, logs, settings).

## Troubleshooting

- **`spawn ffmpeg ENOENT`** — FFmpeg is not installed. Install it (`winget install Gyan.FFmpeg`); the server also finds winget/Chocolatey/Scoop installs even when the terminal PATH is stale.
- **`EADDRINUSE` on 3333** — an ffmpeg-server is already running; close it first.
- **AI features fail** — open `/settings/llm`, add a provider with the right service flags, and use **Uji** to check it.
- **First Remotion render is slow** — Remotion downloads its Chrome Headless Shell (~100 MB) once.
